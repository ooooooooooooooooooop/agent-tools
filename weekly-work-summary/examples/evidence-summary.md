# Example: Evidence-Based Weekly Summary

Evidence scope:

- Repository history.
- Task records.
- Recently changed source and deliverable files.

Summary:

- Monday: Consolidated the week's main workstream from repository and task evidence.
- Tuesday: Verified the highest-signal changes and separated completed work from open issues.
- Wednesday: Reconstructed the remaining work themes without treating file timestamps as proof of completion.

Caveat:

The example is illustrative; a real summary must be rebuilt from the target workspace and requested date window.
