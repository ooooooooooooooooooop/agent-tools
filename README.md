# skills

Public skills repository for agent tooling.

## Included Skills

- `simulate-elite-experts`

## Install

```bash
npx skills add https://github.com/ooooooooooooooooooop/skills --skill simulate-elite-experts
```

## Usage

After installation, trigger the skill with:

```text
$simulate-elite-experts
```
