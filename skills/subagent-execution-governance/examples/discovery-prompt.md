# 探查子代理 Prompt 模板（Discovery Agent）

> 探查子代理：只读，不写，产出 ≤15 条结构化事实。禁止做任何实现决策。

## 模板

```text
目标：只读检查 [仓库根路径/目标范围]，定位 [具体负责人/模块/接入点]。

步骤0：先报告工作目录和只读沙箱探针（pwd、ls/glob 可见性）。

随后：
- 用 grep/glob 定位最多 [N] 个最相关源码文件
- 大文件只读 offset/limit 窗口（禁止全量）
- 禁止修改任何文件、禁止启动服务

最终产出（≤15 条，必须含 file:line）：
1. 现有状态机/数据结构（file:line）
2. 服务 API 签名（file:line）
3. 事件/钩子接点（file:line）
4. 持久化位置（file:line）
5. 配置 schema（file:line）
6. 测试模式与 runner（file:line）
7. 兼容风险与最小改动集合
8. 不可接入的点（含原因）

每阶段简要回报当前进度与发现；
静默超过 5 分钟必须主动报告进展。

验收：返回不超过 15 条要点，每条对应 file:line 证据。
如执行了命令，附命令全文及 exit code/log 摘要。
```

## 关键约束

- **禁止**在探查产出中包含"建议实现方案"或"代码片段"
- 主会话基于探查结果写契约快照，探查子代理不决定实现怎么做
- 如果探查后在主会话写契约前等待超过 5 分钟，探查子代理应主动报告状态
