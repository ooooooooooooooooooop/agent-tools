# Example: Multi-File Change

Request:

Refactor a workflow rule across several skill files and update its tests.

Classification:

- Mode: large task.
- Reason: multiple files, behavior impact, and acceptance criteria.
- Risk: trigger drift or inconsistent rules between skills.

Action:

Define the goal, non-goals, affected files, compatibility constraints, and tests before editing. Use the repository task tracker if the work spans multiple sessions.
