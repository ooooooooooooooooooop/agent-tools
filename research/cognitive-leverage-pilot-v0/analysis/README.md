# Analysis Directory (Cognitive Leverage Pilot V0)

This directory is reserved for post-run comparative analysis, scorecard aggregation, and failure attribution notebooks/scripts.

## Rules for Phase A
- **No comparative conclusions are drawn during Phase A.**
- This directory contains the analysis protocols and verification scripts only.
- In future phases, comparative analysis scripts will consume the artifacts in `runs/` and generate:
  - Multi-dimensional scorecard comparisons (`scorecards.json`)
  - Attribution matrices based on `failure_taxonomy.md`
  - Statistical summaries across the three baselines
